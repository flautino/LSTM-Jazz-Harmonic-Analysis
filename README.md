# JazzHarmonicAnalysis

This project analyzes and predicts jazz chord progressions using an Long Short Term Memory (LSTM) machine learning model. This model outperformed two baselines, a first order markov model and the majority class model, by a significant margin across the root, quality, and extension prediction accuracies as detailed in main.ipynb.
